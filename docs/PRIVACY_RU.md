# Данные и приватность

[English](PRIVACY_EN.md)

## Где хранятся данные

По умолчанию готовая программа хранит карты, ключи, настройки и результаты операций в
`%LOCALAPPDATA%\Proxmark Studio`. Запуск исходников использует `data/personal`.
Папку данных можно открыть через **О программе**. Параметры `--data-dir` и
`--demo` могут выбрать другой профиль.

Удаление приложения сохраняет библиотеку. Для удаления своих данных закройте
приложение и отдельно удалите пользовательскую папку. Экспортированные в другие
каталоги файлы и сделанные вами копии останутся в выбранных местах.

## Шифрование и журналы

Приложение **не шифрует библиотеку**. Ключи MIFARE хранятся в обычной SQLite,
дампы и резервные копии — в базе и файлах. Доступ к ним определяется правами
Windows и защитой самого компьютера.

История консоли сохраняет последние 100 команд, включая введённые параметры.
История, словари, отчёты и вывод клиента могут содержать UID, ключи, пароли и
содержимое карт. Режим клиента `--incognito` не отключает собственные журналы
и историю GUI. Историю консоли можно очистить в её интерфейсе; это не удаляет
данные из других отчётов, библиотеки или резервных копий.

Перед публикацией журнала или снимка экрана просмотрите содержимое. Для
обычного сообщения об ошибке достаточно версии, описания действий и подходящего
фрагмента вывода. Не прикладывайте всю папку библиотеки.

## Сетевые обращения

В коде GUI нет встроенной аналитики, облачной синхронизации или автоматической
отправки библиотеки. Обычная работа по USB или Blue Shark не требует интернета.
Режим TCP соединяет клиент с адресом, который вы указали сами.

GUI также позволяет запускать сценарии комплектного или выбранного вами
клиента. Эти сценарии не ограничены сетевой песочницей. Например, комплектный
`fm11rf08s_full.py` при явном параметре `--validate` отправляет блок 0 карты
внешнему сервису Fudan для проверки подписи; для этого нужен интернет и пакет
`requests`. Без этого параметра данный запрос не выполняется.

Проверяйте назначение сторонних сценариев перед запуском. Установка Python-
пакетов и сборка из исходников тоже могут обращаться к указанным в инструментах
серверам зависимостей. Это отдельные действия, а не отправка библиотеки GUI.

## Что входит в скачиваемый комплект

Комплект содержит программу, клиент, прошивки, публичные ресурсы, лицензии и
исходники компонентов. Личная библиотека разработчика, дампы, ключи и журналы
в него не включены. Изображение интерфейса в README использует демонстрационные
данные.

Эта страница описывает текущую реализацию. Она не заменяет аудит всех сторонних
сценариев и сетевого трафика.

## Архив библиотеки

Архив библиотеки создаётся через **Библиотека…**.
По желанию весь архив защищается паролем (AES-256-GCM, включая имена файлов);
пароль не сохраняется. Без пароля это обычный ZIP с открытыми данными.
Текущая и восстановленная библиотеки остаются незашифрованными. Архив включает
журналы и остальные файлы профиля. [Подробности](LIBRARY_BACKUPS.md#по-русски).
