PROXMARK STUDIO 0.3.0-preview.1
Windows 10 (1903+) / Windows 11, x64

РУССКИЙ
1. Запустите ProxmarkStudio-0.3.0-preview.1-Setup-x64.exe.
   Установка для текущего пользователя, без прав администратора:
   %LOCALAPPDATA%\Programs\Proxmark Studio.
   Ярлыки рабочего стола и меню «Пуск» выбраны по умолчанию.
   Или распакуйте portable ZIP целиком, сохранив все подпапки.
2. Откройте Proxmark Studio через ярлык или ProxmarkStudio.exe.
   Устанавливать Python не нужно.
3. Подключите Proxmark по USB, выберите USB и его COM-порт, нажмите «Подключить».
4. Язык выбирается внизу боковой панели и применяется после перезапуска.
5. Библиотека и настройки: %LOCALAPPDATA%\Proxmark Studio.
   Найти их можно через «О программе» → «Открыть папку библиотеки».

Инструкция: docs/USER_GUIDE_RU.md.
Для Blue Shark используется Bluetooth Classic SPP и исходящий COM-порт Windows.
Перед обновлением или удалением завершите операции и штатно закройте GUI и
клиент Proxmark. Дождитесь завершения прошивки. Удаление программы сохраняет
библиотеку и настройки. Portable-обновление распаковывайте в отдельную папку.
Установка программы и подключение платы не запускают прошивку автоматически.

ENGLISH
1. Run ProxmarkStudio-0.3.0-preview.1-Setup-x64.exe.
   It installs for the current user without administrator rights in:
   %LOCALAPPDATA%\Programs\Proxmark Studio.
   Desktop and Start Menu shortcuts are selected by default.
   Or extract the entire portable ZIP, keeping all subdirectories together.
2. Open the Proxmark Studio shortcut or ProxmarkStudio.exe.
   Python installation is not required.
3. Connect Proxmark over USB, select USB and its COM port, then Connect.
4. Choose your language at the bottom of the sidebar, then restart.
5. Data location: %LOCALAPPDATA%\Proxmark Studio.
   Open it with About → Open library folder.

Guide: docs/USER_GUIDE_EN.md.
Blue Shark uses Bluetooth Classic SPP and an outgoing Windows COM port.
Before updating or uninstalling, finish operations and close the GUI and
Proxmark client normally. Allow firmware installation to finish. Uninstalling
preserves your library and settings. Extract portable updates separately.
Installing the application or connecting a board does not flash firmware.
